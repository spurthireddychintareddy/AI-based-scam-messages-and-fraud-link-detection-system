# AI-based-scam-messages-and-fraud-link-detection-system
AI-based scam message and fraud link detection automatically analyzes text and URLs using machine learning to identify suspicious or malicious patterns. It helps protect users from phishing, fraud, and cyber-attacks by providing quick and accurate threat detection.
Developed an AI-powered system that successfully identified 90% of scam messages and fraudulent URLs.

• Implemented a TF-IDF vectorizer and Naive Bayes classifier to analyse message content and detect
potential scams.
• Built an interactive Streamlit web application with real-time scam detection, suspicious link analysis,
and a user-friendly interface.
